
# Doctor Appointment Booking System

## Description
A full-stack healthcare appointment platform with separate patient and admin experiences.

## Tech Stack
PHP, HTML, CSS, JavaScript, MySQL

## Features
- Patient-facing pages for browsing doctors, booking appointments, and registration/login
- Admin interface for managing bookings
- Relational database schema designed for doctor, patient, and appointment records
- PHP API layer handling the booking logic
